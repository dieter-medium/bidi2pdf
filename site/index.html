bidi2pdf

Renders a URL or HTML to PDF – and screenshots – with headless Chrome over WebDriver BiDi. A Ruby gem and a CLI, built to be driven by scripts, CI and AI agents.

What it is for

  • A web page or HTML file to PDF from the command line, with waits for page load or network idle, cookies, headers and basic auth.
  • HTML in, PDF out: --stdin and --output - pipe without touching a file.
  • Automation and agents: with --json, stdout carries exactly one JSON document per call; failures come back in the same shape with a structured error and a stable exit code; the JSON Schema of every shape is built in.
  • Why does the PDF not look like the page? bidi2pdf diagnose reports console errors, failed requests, font loading, print rules and Paged.js – without producing a PDF.
  • Pages that need steps before printing: declarative recipes, validated without launching a browser.
  • Screen, dark and mobile views of a page as PDF (--media, --color_scheme), and screenshots through the Ruby API, for review.
  • A shared remote Chrome for several processes – Puma workers, job workers – with pre-warmed sessions and a sweeper for leaked ones.
  • Ruby and Rails: a programmatic API and DSL, bidi2pdf-rails for render pdf: in controllers, and RSpec matchers for PDF specs.

Quick start

gem install bidi2pdf
bidi2pdf render --url https://example.com --output example.pdf

Requires Ruby 3.4 or later and Chrome or Chromium – or use the published Docker image.

For agents and CI

# check compatibility - no browser launched
bidi2pdf version --json

# discover the shape of every result
bidi2pdf schema render

# validate a recipe without a browser, then run it
bidi2pdf run recipe.yml --validate
bidi2pdf run recipe.yml --json

# render with a machine-readable result
bidi2pdf render --url https://example.com --output example.pdf --json
Exit codes
Exit codeMeaning
0success
2CLI, configuration or recipe-validation error
3browser or navigation error
4page not as expected (a recipe action or assertion, or a diagnose selector, failed)
6output or PDF generation failure
70unexpected internal error

Details: structured output, stdin/stdout and progress events, diagnose, recipes. A plain-text summary for language models: llms.txt.
